# Komisja Cyfryzacji SSPW

Jesteśmy Komisją Cyfryzacji Samorządu Studentów Politechniki Warszawskiej.

Ta organizacja GitHub jest wspólną przestrzenią na projekty, narzędzia, automatyzacje oraz materiały szkoleniowe rozwijane przez Komisję.

## Co tu znajdziesz

- **projekty** — aplikacje i narzędzia tworzone na potrzeby SSPW i społeczności studenckiej,
- **szkolenia** — materiały, przykłady i ćwiczenia techniczne,
- **dokumentację** — wiedzę potrzebną do rozwijania i utrzymywania naszych rozwiązań,
- **eksperymenty** — prototypy i projekty edukacyjne.

## Jak pracujemy

Staramy się, aby projekty były możliwe do przejęcia przez kolejne osoby i kadencje. Dlatego preferujemy:

- pracę przez Issues i Pull Requesty,
- przegląd zmian przed scaleniem,
- dokumentowanie decyzji i sposobu uruchomienia projektu,
- automatyzację powtarzalnych czynności,
- przechowywanie wiedzy w repozytoriach zamiast wyłącznie „w głowach”.
